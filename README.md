# Sprint_6 

## Структура проекта

```bash
Sprint_6/
├── allure-results/        # результаты тестов для Allure
├── helpers/               # вспомогательные модули
│   ├── constants/         # константы 
│   └── locators/          # локаторы элементов
├── page_objects/          # Page Object Model
├── tests/                 # pytest тесты
├── conftest.py            # фикстуры pytest
├── requirements.txt       # зависимости проекта
└── README.md              # документация проекта
```
### Page Objects

faq_page.py – Открытие страницы, прокрутка к FAQ, клик по вопросу и проверка текста ответа

order_page.py – Полный сценарий оформления заказа: заполнение формы, подтверждение заказа, навигация по логотипам. Методы обёрнуты в @allure.step

### Tests
#### 1. tests/test_faq_section.py
Параметризованный тест, который проверяет, что при клике на каждый вопрос FAQ отображается корректный текст ответа.
#### 2. tests/test_scooter_order.py 
Сценарий оформления заказа самоката:
1. Выбор кнопки заказа (верхняя или нижняя).
2. Заполнение контактной информации и деталей аренды.
3. Подтверждение заказа и проверка сообщения «Заказ оформлен».
4. Переход по логотипу Scooter → возвращение на главную страницу.
5. Переход по логотипу Yandex → открытие Яндекс.Дзен в новой вкладке и проверка, что URL содержит dzen.ru.
###  Запуск тестов и отчётов
Активировать виртуальное окружение:
source venv/bin/activate
pip install -r requirements.txt

Запустить pytest с генерацией Allure результатов:
pytest --alluredir=allure-results

Просмотреть отчёт:
allure serve allure-results
